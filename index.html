TBC Macros

A free command pack for Trimble Business Center. Sixteen tools for drawing and cleaning linework, elevating 2D lines, labeling surfaces, exporting machine-control packages, and moving objects between projects.

Download for Windows Windows installer · all versions & ZIP
Digitally signed by AB Civil Consulting, LLC

Install — about a minute

  1. Close Trimble Business Center if it’s open.
  2. Run the installer and click through it. Windows asks for admin permission; if a blue “Windows protected your PC” screen appears, choose More info → Run anyway (it shows AB Civil Consulting, LLC as the publisher).
  3. Open TBC and type an underscore ( _ ) or ABC in the command search box to find the new commands.

Macros install to C:\ProgramData\Trimble\MacroCommands3\ABCivil. To update, run a newer installer — it replaces the old versions in place. Uninstall from Windows Settings › Apps.

What’s inside

Join Selected LinesMerge lines, bridge gaps, fix direction
Break at OffsetBreak lines at a virtual offset of a reference
Name Lines by LayerAuto-name linework from its layer
Trim Line EndsShave dangling ends off selected lines
Trim Intersecting LinesTrim lines inside/outside an area, with preview
ABC RelayerSticky target layer, Ctrl+R companion
Convert To LinestringCAD lines & arcs to TBC linestrings
Elevate From 3D LinesGive 2D lines elevations from crossing 3D lines
Surface Elevation LabelLive surface elevation label with leader
Surface Slope LabelLabel slope % along a draped line
Design ExporterOne-button DXF / LandXML / VCL machine-control export
Capture Background ImageGeoreferenced background images with world files
Quick Export / Import VCLMove objects & PDFs between TBC projects
Sync Plan ViewsLock two plan views to pan/zoom together
