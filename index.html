TBC Macros
by AB Civil

A free pack of sixteen commands for Trimble Business Center — drawing and cleaning linework, elevating 2D lines, labeling surfaces, exporting machine-control packages, and moving objects between projects.

Download for Windows Windows installer · all versions & ZIP
Signed installer — verified publisher AB Civil Consulting, LLC

Install — about a minute

  1. Close Trimble Business Center if it’s open.
  2. Run the installer and click through it. Windows will ask for admin permission. If a blue “Windows protected your PC” screen appears, choose More info → Run anyway — it shows the verified publisher AB Civil Consulting, LLC.
  3. Open TBC. The commands appear on a new AB Civil ribbon tab, or type an underscore ( _ ) or ABC in the command search box.

Installs to C:\ProgramData\Trimble\MacroCommands3\ABCivil. To update, run a newer installer — it replaces the old version in place. Uninstall cleanly from Windows Settings › Apps.
